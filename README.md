# Week 01 PHP Exercises

Full Stack Web Development - Diploma in IT

Ten PHP exercises using variables, arrays, conditions, loops and functions. All data is fictional.

## How to run
1. Copy the `week01-php-exercises` folder into `C:\xampp\htdocs\`.
2. Start Apache in the XAMPP control panel.
3. Open `http://localhost/week01-php-exercises/exercise01/` (change the number for the others).

## Exercises
1. Citizen profile
2. Age and service eligibility
3. Household member summary
4. Dzongkhag service counter
5. Record search (use `?q=name` in the address bar to change the search)
6. Profile validation
7. Service fee calculator
8. Role permission checker
9. Records report
10. Command dashboard (use `?data=messy` to see the invalid dataset)
